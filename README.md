# Indo Media Kreasi — Website

Website profil perusahaan Indo Media Kreasi — Event Organizer & Exhibition Specialist di Pekanbaru, Riau.

## Struktur Project
- `index.html` - Struktur utama halaman website
- `styles.css` - Styling CSS responsif, tema gelap modern, dan animasi
- `script.js` - Navigasi mobile menu, filter portofolio, dan form WhatsApp handoff
- `vercel.json` - Konfigurasi deployment untuk Vercel

## Deployment ke Vercel via GitHub
1. Upload/Push repository ini ke GitHub.
2. Buka dashboard [Vercel](https://vercel.com).
3. Klik **"Add New..."** -> **"Project"**.
4. Hubungkan akun GitHub Anda dan pilih repository ini.
5. Klik **"Deploy"**. Vercel akan otomatis mendeteksi file statis dan website Anda langsung online!
